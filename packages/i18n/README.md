# @suskii/i18n

**Created with the first user-facing copy** (phase 1 components or the phase 4 homepage, whichever
comes first). Not a workspace yet (no `package.json`).

Message catalogs for `en-NG` (default), `en-GB` and `en-US` (`fr` and `pcm` later) and locale-aware
formatting helpers. Supported locale codes already live in `@suskii/shared` (`SUPPORTED_LOCALES`).
The phase 0 app shells render only the brand name, so no copy exists yet.
