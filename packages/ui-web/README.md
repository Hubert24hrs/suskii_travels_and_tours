# @suskii/ui-web

**Built in phase 1.** Not a workspace yet (no `package.json`).

Accessible web component library on Radix UI primitives, styled only through
`@suskii/design-tokens`: Button, Input, Tabs, SegmentedControl, Combobox, DateRangePicker,
PassengerPicker, Card, DealCard, DestinationCard, Badge, TrustBar, Skeleton, Modal/Sheet, Toast.
Documented in Storybook with axe checks.
